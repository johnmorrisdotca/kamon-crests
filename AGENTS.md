# Agents: Kamon Crests

For anyone drawing a crest, and the agent helping them: **read [docs/guides/draw-a-crest.md](docs/guides/draw-a-crest.md) in full first.** It has the steps, the side-by-side sheet every crest needs, and the prompts. The rules below hold for every change.

- **Shapes come only from the public-domain 1892 crest book (NDL 780550).** Wikipedia and Wikimedia Commons drawings are mostly CC BY-SA and are for checking only: a few overall numbers at most (a count, an aspect ratio, a main angle), never placed features, never iterating toward their outline, never fitting or search scripts against them, never a trace. Never use a modern crest book, website (irohakamon.com included), font, clip-art set or software. No book cell means the crest is not drawn. Name every number's source in the crest's `source` and note.
- **No crest is done until a person has looked at its side-by-side sheet** (ours, the book cell, ours over the book cell, the Commons picture if any, our guides). Passing tests is not the bar.
- **Read [docs/construction-rules.md](docs/construction-rules.md) before touching a crest.** It is every rule a crest is drawn by, each with the test that holds it or "checked on the sheet". Required, every time.
- **Ports.** Only 8850 to 8874 (this project's block): 8850 demo and dev server, 8851 browser tests, 8852 pictures, 8853 and up for anything else and for worktrees. Every dev server and every Playwright run names its port explicitly: `node scripts/serve.mjs 8850` accepts no other. A `next dev`-style default is a bug.
- **Checks.** `pnpm check` is the gate: lint, types, build, every export's documentation, the tests (sizes included) and the packed package. Commit and push only when it passes, chained with `&&`.
- **Crests are generated.** Everything under `src/crests/`, `src/steps/` and `src/data/`, and `docs/catalogue.md`, `docs/sizes.md` and `docs/strings-ja.md`, is written by `pnpm data` from `scripts/crests/`. Never edit one by hand; change the crest's definition and run `pnpm data`.
- **Drawn from the construction, or from a public-domain period book.** A geometric crest is drawn from circles, arcs, lines and curves placed by its traditional construction. An organic crest may be vectorised from a crest book printed before 1930 that the National Diet Library marks 保護期間満了, cleaned and made exactly symmetric, with the book, its NDL permalink, the frame, the place and the day read in the crest's `source` (it lands in `docs/provenance.md`) and in `NOTICE.md`. Never from a modern book, a share-alike image or a picture of unknown licence (those are for comparing only), and no scan or crop is ever put in the repository. See `docs/guides/how-crests-are-constructed.md`.
- **Words in both languages.** Anything a person reads in the data is in English and in Japanese; `docs/strings-ja.md` lists every Japanese string beside its English for review.
- **The family's own files are the family's:** `demo/family.css`, `scripts/family-template.mjs` (this copy adds Kamon Crests to the list), `scripts/family-readme.mjs`, `scripts/readme-lint.mjs`, `scripts/readme-pictures-lib.mjs`, `scripts/release-notes.mjs`, `scripts/community/`.
- **Commits carry a person's name, never a tool's.** Each commit is authored by the person contributing, under their own name and email. No co-author trailer naming a model or tool, no line saying a tool made the change, and no tool or model name in a commit, pull request, code, comment or doc.

- **A redrawn crest means new README pictures.** After any change to a crest's drawing, run `pnpm pictures` and commit `docs/images` and `docs/pictures-drawings.sha256` with it; `src/pictures.test.ts` fails until you do.
