## 家紋は写し取るのではなく、割り付けて描く

家紋は、いくつかの円と線でできています。昔の紋章上絵師は、コンパスと定規で家紋を割り付けました。輪のための円、中心を通る線、花弁が出会う位置のための二つ目の円。この割付が、家紋の作図の基になります。このパッケージの幾何学的な家紋は、その通りに書かれています。補助線を引き、そこから図形を描く小さな関数です。いくつかの円では割り付けられない葉や花の家紋は、国立国会図書館の著作権の切れた明治の紋帳から描き起こしています。紙面の線画を塗りつぶして曲線に変換し、整え、半分（または葉一枚）を残して正確に左右に返したり回したりするので、対称は木版のゆがみではなく割付のとおりです。そうした家紋には、紋帳とコマ、紙面上の位置を記しています（[出典](../../provenance.md)）。ラスター画像は埋め込まず、どんな大きさでもパスはきれいなままです。

もっとも厳密に描いた家紋（葵、巴、違い鷹の羽、兎、三つ銀杏）は、コンパスの円の弧と定規の直線だけで描いています。円は、格子点の上に整数の幅で置くか、すでに描いた円に接するように置きます。アニメーションが最初に描く補助線は、その同じ円です。

どの家紋も、一つのページ（200×200の単位、中心は100, 100、割付の円の半径は96）の上にあります。線の太さは一つの尺度から取るので、家紋どうしがそろって見えます。細輪は6.4、中太輪は16.8（実際の丸に紋から測った値。出典を参照）で、輪と図柄の間に3.5の白を残します。

## 作図が持つもの

```ts
import { crestSteps } from "@johnmorrisdotca/kamon-crests/load";

const construction = await crestSteps("maru-ni-mitsu-uroko");
console.log(construction?.guides.length, construction?.shapes.length, construction?.steps.length);
```

- **補助線**：割付のコンパスの円と定規の線で、それぞれパスです。
- **図形**：完成した家紋のパスで、描く順に並んでいます。それぞれが一つの部品（`"frame"` または図柄のID）に属し、塗り（`fill`）か、一定の太さの線（`stroke`）です。
- **手順**：再生される順番です。すべての補助線、次に図形のまとまりごと、最後に補助線を消します。

図形が家紋そのものです。静止したSVGも、アニメーションの最後のコマも同じパスから作られ、テストで一致を確かめています。

## アニメーション

どの家紋も、漢字の筆順のように、自分で描いていけます。まず補助線を細く描き、次に各図形を輪郭としてなぞり、塗りつぶし、最後に補助線を消して、完成した家紋を残します。SVGとCSSのキーフレームだけで、スクリプトもライブラリも使いません。

```ts
import { animatedCrest } from "@johnmorrisdotca/kamon-crests/load";

const svg = await animatedCrest("kikyo", { speed: 1.5, loop: true });
```

要素なら `<kamon-crest crest="kikyo" size="200" animate loop speed="1.5">` です。クリックするとやり直します。動きを減らす設定の読者には、完成した家紋をすぐに見せます。`stepCaption(step, construction, "ja")` は、各手順が何をするかを一文で返すので、図の下の説明に使えます。

## 穴と偶奇規則

葉の中の葉脈や切れ込みは、同じパスの中に、図形の内側にすっかり収まる穴として、偶奇規則で抜いています。マスク、クリップ、グラデーション、色は使わないので、ページ内の別のIDとぶつかることがありません。
