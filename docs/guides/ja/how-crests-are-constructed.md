## 家紋は割り付けて描くか、昔の紋帳から描き起こす

家紋は、いくつかの円と線でできています。昔の紋章上絵師は、コンパスと定規で家紋を割り付けました。輪のための円、中心を通る線、花弁が出会う位置のための二つ目の円。この割付が、家紋の作図の基になります。このパッケージの幾何学的な家紋は、その通りに書かれています。補助線を引き、そこから図形を描く小さな関数です。いくつかの円では割り付けられない葉や花の家紋は、国立国会図書館の著作権の切れた明治の紋帳から描き起こしています。紙面の線画を塗りつぶして曲線に変換し、整え、半分（または葉一枚）を残して正確に左右に返したり回したりするので、対称は木版のゆがみではなく割付のとおりです。そうした家紋には、紋帳とコマ、紙面上の位置を記しています（[出典](../../provenance.md)）。ラスター画像は埋め込まず、どんな大きさでもパスはきれいなままです。

もっとも厳密に描いた家紋（葵、巴、違い鷹の羽、兎、三つ銀杏）は、コンパスの円の弧と定規の直線だけで描いています。円は、格子点の上に整数の幅で置くか、すでに描いた円に接するように置きます。アニメーションが最初に描く補助線は、その同じ円です。

どの家紋も、一つのページ（200×200の単位、中心は100, 100、割付の円の半径は96）の上にあります。線の太さは一つの尺度から取るので、家紋どうしがそろって見えます。細輪は6.4、中太輪は16.8（実際の丸に紋から測った値。出典を参照）で、輪と図柄の間に3.5の白を残します。

## 作図が持つもの

```ts
import { crestSteps } from "@johnmorrisdotca/kamon-crests/load";

const construction = await crestSteps("maru-ni-mitsu-uroko");
console.log(construction?.guides.length, construction?.shapes.length, construction?.steps.length);
```

- **補助線**：割付のコンパスの円と定規の線で、それぞれパスです。
- **図形**：完成した家紋のパスで、描く順に並んでいます。それぞれが一つの部品（`"frame"` または図柄のID）に属し、塗り（`fill`）か、一定の太さの線（`stroke`）です。
- **手順**：再生される順番です。すべての補助線、次に図形のまとまりごと、最後に補助線を消します。どの手順にも `op` があります。`centres` は同じ幅の円の中心に印をつけ、`guide` は円を描くか直線を引き、`mark` はコンパスを円の上で進め、`trace` と `thicken` は輪郭に墨を入れ、`draw` は形のまとまりを塗り、`turn` は同じ形をほかの位置にもう一度作り、`fade` は補助線を消します。

図形が家紋そのものです。静止したSVGも、アニメーションの最後のコマも同じパスから作られ、テストで一致を確かめています。まだ描き直し中の家紋（`redrawing: true`）には補助線も手順もなく、完成した形で表示されます。

どの家紋にも、作り方を一行で書いた英語と日本語の文があります。この文は `manifest` の記録には入っていません。手順と同じファイルから `crestConstruction(id)` で読み込みます。

```ts
import { crestConstruction } from "@johnmorrisdotca/kamon-crests/load";

const text = await crestConstruction("maru-ni-mitsu-uroko");
console.log(text?.en, text?.ja);
```

## アニメーション

どの家紋も、漢字の書き順のように、自分を描いて見せます。職人の六つの段階の順で、手順の説明（`stepCaption`、英語と日本語）に段階の名前が出ます。

1. **コンパスの下書き。** コンパスの幅ごとに描きます。幅には小さい順に1から番号をつけます。同じ幅の円を描く前に、中心に印（点と、その横に幅の番号）をつけます。それから円を一つずつ描きます：「コンパスを幅2に合わせ、2の印に針を置いて、円を描く」。上を通る部分があるとき、下の部分のすき間をはさむ円は「重なりのすき間の円を描く」と出ます。
   六角形や三角形の角の印も、ここでつけます。コンパスをその円の幅のまま、いちばん上から時計回りに円の上で進めます（`mark` の手順）。
2. **定規の下書き。** 直線は全部、割付の円の端から端まで引きます。平行な線はまとめて引きます。棒や四角は、交わる長い線の間のすき間で、形の辺のところだけを引くことはありません。
3. **必要な部分だけなぞる。** 形のまとまりごとに、輪郭を、すでに紙の上にある円と直線に沿って、細い線でなぞります。
4. **輪郭を太くする。**
5. **塗る。** 形のまとまりごとに塗り、一つ分ができたら、ほかの位置にも作ります。
6. **仕上げ。** 下書きを消すと、家紋ができあがります。

円を描いている間と、弧に墨を入れている間は、コンパスの脚が出ます。その円の中心からペン先までの細い線で、ペン先について回り、その間は中心の点が太くなります。描き終わると消えます。弧が、その中心に立てたコンパスで描かれたことが分かります。

補助線のほかに、切り替えが四つあります。`animatedSvg` と `stepSvg` のオプションで、`<kamon-crest>`（または絵を入れている要素）の属性でもあります：`centres`（中心の印）、`widths`（幅の番号）、`fill`（塗り）、`compass-arm`（コンパスの脚。オプションは `compassArm`）。`off` または `false` で消えます。塗りを消すと、家紋は線画になります。形の輪郭（作図に使った弧と直線そのもの）だけを描き、塗りません。白い線は、その両側の二本の線として見えます。`staticSvg(construction, { fill: false })` は、できあがった家紋の線画です。作図データの円には、中心（`at`）と幅の番号（`width`）が入っています。

コンパス幅の見本は、下書きが紙の上にある間、家紋の横に出ます。その家紋が使うコンパスの幅を、番号の順に一つずつ、その幅にコンパスを開いた形で描きます。円の半径と同じ長さの線（家紋と同じ縮尺）で、左端に中心の点と番号があります。コンパスをいま合わせている幅、つまり最後に描いた円の幅は、太く描かれます。家紋の200×200の正方形の外側の余白に置くので、家紋は動きも縮みもしません。見本が出ている間は、絵の枠が横に広がるか（`widthsKey: true` または `"right"`）、下に伸びます（`widthsKey: "below"`）。幅の種類が多い家紋では、見本を何列かに分けます。補助線を消すときに一緒に消え、円のない家紋には出ません。止めた手順（`stepSvg`）にも同じ見本が出て、最後に描いた円の幅が太く描かれます。既定では出ません（`widthsKey: true`、または `widths-key="on"` で出します）。ページの枠が変わらないようにするためです。

墨入れと、くり返しの位置の見せ方を変える切り替えが、あと二つあります。どちらも、描かれる形は変えません。`inkDraw`（属性は `ink-draw`）は既定でオフです。`inkDraw: true`（`ink-draw="on"`）にすると、なぞる手順も太くする手順も、それぞれ二秒半から四秒かけて、ペンが輪郭を一本ずつ時計回りに進み、細い線の上に太い線を重ね、弧ではコンパスの脚がペン先について動きます。指定しなければ、輪郭は一手順一秒足らずで、すばやく浮かび上がります。`fullBuild`（`full-build="on"`）は既定でオフです。オンにすると、`fullBuilt(construction)` が `turn` の手順を、各位置を作る手順に置き換えます。最初の一つから時計回りに、一か所ずつ、その位置に円を描き（先に中心に印をつけます）、直線を引き、輪郭をなぞり、太くして、塗ります。位置ごとの円と直線は、その場所で描いたものです。写したり、裏返したりはしません。手順には `place`（何か所目か、その部分に全部で何か所あるか）が入り、説明に使います。できあがる家紋は、どちらでも同じです。

補助線は、円まるごとか、定規の直線だけです。円弧だけの補助線はありません。弧を使う円は、必ず先に一周すべて描き、まっすぐな辺は、先に引いた直線の上にあります。同じ形をくり返す家紋（三枚の葉、十六枚の花弁）は、まず一つ分を、その円もすべて含めて描き上げます。そのあと `turn` の手順ひとつで、ほかの位置を時計回りに一か所ずつ、すばやく回ります。その位置に同じ円と直線を描き、墨を入れてから、次の位置へ進みます。データに入っている円は一つ分だけです。円はどれも上から時計回りに描き、一つの部分の円はコンパスの幅の小さい順、直線はそのあとで、平行な線ごとにまとめて、上から順に引きます。写した図形は、データの `turn`（中心まわりの時計回りの角度）と `flip` で、どう写したかを示します。描き直しの済んだ家紋はすべて、テストでこの決まりを確かめています。SVGとCSSのキーフレームだけで、スクリプトもライブラリも使いません。

```ts
import { animatedCrest } from "@johnmorrisdotca/kamon-crests/load";

const svg = await animatedCrest("kikyo", { speed: 1.5, loop: true });
```

要素なら `<kamon-crest crest="kikyo" size="200" animate loop speed="1.5">` です。クリックするとやり直します。動きを減らす設定の読者には、完成した家紋をすぐに見せます。`stepCaption(step, construction, "ja")` は、各手順が何をするかを一文で返すので、図の下の説明に使えます。

## 穴と偶奇規則

葉の中の葉脈や切れ込みは、同じパスの中に、図形の内側にすっかり収まる穴として、偶奇規則で抜いています。マスク、クリップ、グラデーション、色は使わないので、ページ内の別のIDとぶつかることがありません。
