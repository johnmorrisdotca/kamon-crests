## タグ

```html
<kamon-crest crest="mitsuba-aoi" size="120"></kamon-crest>
```

`import "@johnmorrisdotca/kamon-crests/element/define"` か、CDNのスクリプトタグ一つで登録します。家紋はページ自身のドキュメントの中に、シャドウルートなしで、文字色で描かれます。要素か親に `color: #8a1c1c` を指定すると、その色になります。属性名が `id` でなく `crest` なのは、HTMLの `id` は一ページに一度しか使えないのに、家紋は二度表示することがあるからです。

## 属性

| 属性 | はたらき |
| --- | --- |
| `crest` | 家紋のID（ゆるい書き方でも可）。 |
| `size` | `small`・`medium`・`large`、またはピクセル数。指定がなければ `1em`。 |
| `animate` | 一手ずつ描きます。 |
| `speed` | 1が標準の速さです。 |
| `loop` | ページを閉じるまで、くり返します。 |
| `guides` | `off` で、アニメーションから補助線を除きます。 |
| `centres`、`widths`、`fill`、`compass-arm` | `off` で、円の中心の点、その横のコンパス幅の番号、塗り、コンパスの脚を消します（塗りを消すと、形の輪郭だけの線画になります。コンパスの脚は、円や弧を描いている間だけ出る、中心からペン先までの細い線です）。この四つは絵のほうが読みます。要素、またはその外側の要素につけます。再生中や再生後の絵にはすぐ効き、止めた絵（`step()`）には次に描くときに効きます。要素のプロパティはありません。 |
| `replay` | `off` で、クリックやEnterでのやり直しを止めます。 |
| `controls` | 再生と一時停止、前の手順、次の手順、手順を選ぶスライダー、手順の説明を表示します。 |
| `color`・`background` | 通常のCSSの色。 |
| `label`・`lang` | 読み上げる文言と、その言語。 |
| `loading` | `lazy`（標準）または `eager`。 |

どの属性もプロパティでもあります。`play()` は作図を最初から描き直し、終わったときに解決します。`ready` は家紋が描かれると解決し、該当する家紋がなければ `false` になります。

## 一時停止・再生・手順送り

```ts
const crest = document.querySelector("kamon-crest");
crest.pause();          // アニメーションをその場で止める
await crest.play();     // 止めたところから続ける（止めていなければ最初から描き直す）
await crest.step(3);    // 手順0から3までを済ませた状態で止める。-1は何も描いていない状態
console.log(crest.at, crest.paused); // 3 true
```

`step(n)` は止まった図を表示します。そこまでに描いた補助線と図形がすべてあり、描きかけのものはありません。戻り値は、実際に止まった手順の番号です。そのあとの `play()` は次の手順から続け、最後の手順からなら最初に戻ります。`at` はいまの手順の番号、`paused` は止まっているかどうかです。

`controls` を付けると、同じ操作が家紋の下に並びます。再生と一時停止のボタン、前の手順と次の手順、手順ごとに止まるスライダー（最初は何も描いていない状態）、そして止めているあいだの手順の説明です。文言は `lang` に合わせて英語か日本語になります。

要素にフォーカスがあるときのキー操作：スペースで止める・続ける、左右の矢印で前後の手順へ、Enterで最初から描き直します。

## 部品を一つだけ見せる

```ts
await crest.isolate("frame");                    // 輪だけをはっきり、ほかは薄く。輪の二つの円も出ます
await crest.isolate("hollyhock");                // 図柄をIDで指定。その図柄のための補助線をすべて出します
await crest.isolate("hollyhock", "count");       // 三枚のうちの一枚。次の手順で、ほかの位置に回して写します
await crest.isolate("hollyhock", "arrangement"); // 回して写す位置の線と、裏返す軸
await crest.play();                              // その部品の手順だけを描きます
await crest.clear();                             // 家紋全体に戻します
```

`isolate(part, show?)` は、部品を一つだけ見せて止めます。その部品の形ははっきり、家紋のほかの部分は薄く、補助線はその部品のものだけです。`part` は `"frame"`（枠）か、レコードにある図柄のIDです。`clear()` を呼ぶまで、`step()`、`play()`、操作ボタンはその部品の手順だけを進みます。`step(-1)` のあとに `play()` を呼ぶと、その部品だけを描きます。枠のない家紋の枠のように形のない部品では、家紋全体が薄くなります。`crest` を変えると、部品の指定は外れます。

作図データの形と補助線には、どの部品のものか（`part`）と、何番目の単位か（`unit`：実際に描く単位が0、それを回して写した位置が1から）が入っています。`/animate` の `isolated(construction, part, show?)` は、同じ見せ方をデータとして返します。手順を自分で描くページ用です。

## イベント

描かれたときに `kamon-load`、アニメーションが終わったときに `kamon-end`、何も描けなかったときに `reason` 付きの `kamon-error` が出ます。再生を始めたとき・続けたときに `kamon-play`、止めたときに `kamon-pause`、`step()`・操作ボタン・矢印キーで手順に止まったときに `kamon-step` が出ます。あとの二つは `step`（止まっている手順の番号）と `steps`（手順の数）も持ちます。どれも `detail` に `{ crest }` を持ち、バブリングし、composedです。

## 動きを減らす設定

読者が動きを減らす設定にしている場合、`animate` はアニメーションなしで、完成した家紋をすぐに表示します。手順送りは使えます。どの手順も止まった図だからです。
