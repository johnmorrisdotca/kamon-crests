---
title: 家紋の利用について
section: concept
order: 7
description: 図の出どころ、ライセンス、いくつかの家紋についての二つの注意です。
---

伝統的な図案は誰のものでもありません。このパッケージの図はすべて、その家紋の作図から、このパッケージのために描いたもので、MITライセンスです。家紋の本、ソフトウェア、クリップアートからの転用はありません（それらの図はそれぞれの作者のものです）。

二つの注意を、事実として、法的助言ではなく記します。

- 日本の商標法第4条第1項第1号は、菊花紋章（またはそれに類似する標章）を商標として登録することを認めていません。
- 桐は、日本政府の紋章です。

どちらも参考として収録したもので、誰かのブランドとして使うためのものではありません。企業のロゴは描きません。`usedBy` は関係を出典付きで述べるだけです。図のライセンスにかかわらず、国の法律が家紋や紋章の使い方を制限することがあるので、商用で使う前にご確認ください。
