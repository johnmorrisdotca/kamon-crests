# 複雑さ：点数、目盛り、級

家紋を描くのがどのくらい大変かを、並べ替えや表示に使える一つの数にしたものです。家紋の数（円・直線・弧など）だけから計算し、手で入力することはありません。英語版は [../complexity.md](../complexity.md) です。この日本語は、まだ日本語を母語とする方の確認を受けていません。

## 計算のしかた

```
点数（score） = 3 × 弧 + 2 × 円 + 1 × 直線 + 5 ×（コンパスの幅の種類 − 1）
目盛り（meter） = 25 × log10(点数) を四捨五入（0から100まで）
級（grade） = 1から5。点数で分けます：25未満、25〜99、100〜299、300〜999、1000以上
```

数は、アニメーションが実際にする回数です。回したり裏返したりして作る位置もすべて数えます（[数について](parts-and-search.md)）。

## なぜこの重みか

- **弧は3。** 弧に墨を入れるのが、いちばん気を使う作業です。交点から交点までだけ、円の上を正確になぞります。
- **円は2。** 円は一回で描けますが、先に針を正しい中心に置く必要があります。
- **直線は1。** 定規の線はいちばん速く引けます。二つの点と定規だけです。
- **コンパスの幅を変えるごとに5。** 幅を合わせ直すのが、いちばん時間のかかる動きです。幅が30種類の家紋は、同じ数の円でも幅が3種類の家紋よりずっと大変です。

## 目盛り

目盛りは、棒で見せるためだけのものです。点数を0から100に直します。決まった物差しで、ほかの家紋との比べ方ではありません。家紋が増えても、その家紋の目盛りは変わりません。点数が10倍になるごとに25上がります。

| 点数 | 1 | 10 | 100 | 1000 | 10000 |
| --- | --- | --- | --- | --- | --- |
| 目盛り | 0 | 25 | 50 | 75 | 100 |

## 級

級は、点数をきりのよい数で分けたものです。これも決まっているので、家紋が増えても、その家紋の級は変わりません。

| 級 | 点数 | 日本語 | English |
| --- | --- | --- | --- |
| 1 | 25未満 | 入門 | Simple |
| 2 | 25〜99 | 初級 | Easy |
| 3 | 100〜299 | 中級 | Moderate |
| 4 | 300〜999 | 上級 | Hard |
| 5 | 1000以上 | 名人 | Master |

いまは、蛇の目が15点（入門、目盛り29）、丸に三つ葉葵が1249点（名人、目盛り77）です。五つの級すべてに家紋があります。

## コードで使う

```ts
import { GRADES, findCrests, rankCrests, topCrests } from "@johnmorrisdotca/kamon-crests/search";
import { manifest } from "@johnmorrisdotca/kamon-crests/manifest";

const stats = manifest("maru-ni-kikyo")?.stats;
console.log(stats?.score, stats?.meter, stats?.grade);   // 216 58 3
console.log(GRADES[2].en, GRADES[2].ja);                 // "Moderate" "中級"

rankCrests();                        // 点数の少ない順に、すべての家紋
topCrests(5);                        // いちばん複雑な五つ
findCrests({ grade: 4 });            // 上級の家紋すべて
findCrests({ meter: { min: 70 } });  // 目盛りでも、ほかの数と同じように検索できます
```

昔の紋帳からなぞって描き直している家紋には、目盛りを表示しません。数がなぞった絵のものだからです。`rankCrests()` では最後に並び、`topCrests()` には入りません。
